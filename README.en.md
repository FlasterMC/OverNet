# Overwisp

**English** · [Русский](README.md)

> **This is a test version of the browser.** The project is experimental and I am not sure I will keep developing it. Expect bugs; updates may stop at any time.

A browser from the OverClouds family based on [Zen Browser](https://github.com/zen-browser/desktop) and Firefox. Tabs on the left, folder-like groups and handy workspaces.

## Features

- **Sidebar tabs** in the spirit of Arc and Vivaldi: pinned tabs, workspaces and groups that fold like folders.
- **Automatic updates** inside the browser.
- **Firefox engine (Gecko)**: extensions, privacy, no telemetry.

Planned: Russian websites working without installing certificates, and voice-over video translation.

## Installation

Everything is on the [releases](https://github.com/FlasterMC/Overwisp/releases) page.

- **macOS on Apple Silicon (M1 and newer):** `Overwisp-<version>.dmg`.
- **macOS on Intel:** `Overwisp-<version>-Intel.dmg`, requires macOS 10.15 or newer.
- **Windows:** `Overwisp-Setup-<version>.exe`.
- **Linux:** `Overwisp-<version>-linux-x86_64.tar.xz`, extract it and run `zen`.

On macOS drag Overwisp into Applications. The app is not signed with an Apple certificate, so on first launch open System Settings → Privacy & Security and click "Open Anyway".
